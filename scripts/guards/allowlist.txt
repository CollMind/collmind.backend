# Guard allowlist — susturulmuş bulgular
#
# Format: <guard-adı>|<anahtar>|<gerekçe>
#
#   <anahtar> = <dosya-yolu>:<satır>   → kaynak kod bulgusu
#             | <bulgunun tam anahtarı> → ör. `db:collmind_tpm` (ortam bulgusu)
#             | ENV                    → SON ÇARE joker: o guard'ın dosya:satır
#                                        biçiminde OLMAYAN *her* bulgusunu susturur.
#                                        Geniştir — tam anahtar yazabiliyorsan onu yaz.
#
# Gerekçesiz veya alan sayısı eksik satır GEÇERSİZDİR ve guard'lar parse hatası
# verip exit 2 döner (sessizce yok saymaz). Faz 2'de guard'lar bloklayıcı olduğu
# için sessiz yok sayma "susturma çalışıyor sanılıyor" durumunu üretirdi.
#
# `#` ile başlayan satırlar ve boş satırlar yok sayılır.
#
# Geçerli guard adları:
#   migration-schema | ledger-direction | financial-ordering | schema-isolation
#
# ALLOWLIST SON ÇARE'DİR. Bilinen bir yanlış pozitif deseni varsa guard'ın
# kendisi tanımalıdır — buraya satır eklenmemelidir. Örnek: `'main.x'::regclass`
# şema-güvenlidir ve Faz 2'de migration-schema guard'ının içinde çözüldü;
# allowlist'e girmedi.
